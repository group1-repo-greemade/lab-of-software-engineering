# معماری فنی TechMart

پروژه با معماری لایه‌ای سبک و تفکیک مسئولیت‌ها پیاده‌سازی شده است:

1. **Presentation:** فایل `public/index.html` ساختار صفحه را تعریف می‌کند، `public/css/style.css` ظاهر و واکنش‌گرایی را مدیریت می‌کند و `public/js/app.js` رویدادهای رابط و درخواست‌های HTTP را اجرا می‌کند.
2. **Routes / API:** فایل‌های `src/routes` درخواست‌ها را دریافت، ورودی‌ها را بررسی و سرویس مناسب را فراخوانی می‌کنند.
3. **Middleware:** فایل `src/middleware/auth.js` احراز هویت و کنترل نقش مدیر را انجام می‌دهد.
4. **Services:** سرویس‌های `cart.service.js` و `order.service.js` منطق سبد خرید، کنترل موجودی، محاسبه مبلغ و گردش وضعیت سفارش را در خود نگه می‌دارند.
5. **Persistence:** `src/data/store.js` خواندن و نوشتن فایل JSON را مدیریت می‌کند. عملیات نوشتن صف‌بندی می‌شوند و ابتدا در فایل موقت نوشته و سپس جایگزین می‌شوند.

## قواعد دامنه

- رمز عبور به‌صورت متن خام ذخیره نمی‌شود و با bcrypt هش می‌شود.
- مشتری فقط سفارش‌های متعلق به حساب خود را مشاهده می‌کند.
- عملیات مدیریت محصولات و سفارش‌ها فقط با نقش `admin` مجاز است.
- قیمت نهایی سفارش در سرور محاسبه می‌شود.
- تغییر وضعیت سفارش فقط در انتقال‌های مجاز انجام می‌شود.
- اطلاعات اقلام سفارش هنگام خرید snapshot می‌شود تا تاریخچهٔ سفارش ثابت بماند.

## محدودهٔ تراکنش

در نسخهٔ آموزشی، هر تغییر داده با صف نوشتن سریالی در فایل JSON انجام می‌شود. این روش برای اجرای محلی مناسب است اما معادل تراکنش‌های پایگاه داده‌ای چندکاربره نیست؛ برای نسخهٔ عملیاتی باید از پایگاه داده‌ای با تراکنش ACID استفاده شود.
