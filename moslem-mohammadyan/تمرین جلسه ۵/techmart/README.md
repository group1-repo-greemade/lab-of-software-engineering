# TechMart — فروشگاه اینترنتی آموزشی

TechMart یک پروژهٔ فروشگاه اینترنتی فارسی برای درس مهندسی نرم‌افزار است. پروژه فقط یک قالب ظاهری نیست؛ بخش کاربری، API سمت سرور، احراز هویت، سبد خرید، ثبت سفارش، کنترل موجودی و پنل مدیر دارد. هفت نمودار UML نیز در پوشهٔ `diagrams` قرار گرفته‌اند.

## فناوری‌ها

- **Frontend:** HTML5، CSS3 و JavaScript ماژولار (بدون فریم‌ورک)
- **Backend:** Node.js 20+ و Express
- **Authentication:** نشست مبتنی بر Cookie و هش رمز عبور با bcryptjs
- **Data storage:** فایل JSON محلی با نوشتن اتمیک و صف عملیات نوشتن
- **Security baseline:** Helmet، محدودسازی درخواست‌های احراز هویت، اعتبارسنجی ورودی‌ها و کوکی HttpOnly
- **UML:** هفت فایل PlantUML با پسوند `.puml`

## راه‌اندازی در VS Code

۱. Node.js نسخهٔ ۲۰ یا بالاتر را نصب کنید.

۲. پوشهٔ پروژه را در VS Code باز کنید: `File > Open Folder`.

۳. ترمینال VS Code را باز کنید و وابستگی‌ها را نصب کنید:

```bash
npm install
```

۴. فایل تنظیمات نمونه را کپی کنید و مقدار `SESSION_SECRET` را تغییر دهید. در ویندوز PowerShell:

```powershell
Copy-Item .env.example .env
```

در macOS یا Linux:

```bash
cp .env.example .env
```

۵. سرور توسعه را اجرا کنید:

```bash
npm run dev
```

۶. در مرورگر آدرس زیر را باز کنید:

```text
http://localhost:3000
```

برای توقف سرور در ترمینال `Ctrl + C` را بزنید.

> در اولین اجرا، فایل `data/store.json` به‌صورت خودکار ساخته می‌شود و محصولات اولیه و حساب مدیر در آن قرار می‌گیرند. این فایل در Git نادیده گرفته شده است تا اطلاعات محلی کاربران و سفارش‌ها ناخواسته آپلود نشود.

## حساب مدیر آزمایشی

در اجرای اول:

```text
Email:    admin@techmart.local
Password: Admin123!
```

با این حساب وارد شوید تا دکمهٔ پنل مدیریت را ببینید. در نسخهٔ فعلی رابط تغییر رمز عبور مدیر پیاده‌سازی نشده است؛ این حساب فقط برای نمایش کلاسی است و نباید برای یک سایت عمومی استفاده شود.

## قابلیت‌های پیاده‌سازی‌شده

### مشتری

- مشاهده، جست‌وجو، مرتب‌سازی و فیلتر محصولات
- افزودن محصول به سبد خرید، تغییر تعداد و حذف محصول
- نگهداری موقت سبد مهمان در مرورگر و انتقال آن به حساب پس از ورود
- ثبت‌نام و ورود با ایمیل و رمز عبور هش‌شده
- ثبت سفارش با آدرس و شماره همراه
- انتخاب پرداخت در محل یا پرداخت آزمایشی
- مشاهدهٔ سفارش‌های قبلی و وضعیت آن‌ها

### مدیر

- مشاهدهٔ آمار کلی فروشگاه
- افزودن و حذف محصول
- مشاهدهٔ سفارش‌های همهٔ مشتریان
- تغییر وضعیت سفارش طبق گردش وضعیت تعریف‌شده

### منطق سفارش

مبلغ هر سفارش در سمت سرور محاسبه می‌شود و به مبلغ ارسالی مرورگر اعتماد نمی‌شود. موجودی پیش از ثبت سفارش کنترل و پس از ثبت سفارش کم می‌شود. آیتم‌های سفارش، نام و قیمت لحظهٔ خرید را نگه می‌دارند تا تغییر بعدی محصول، جزئیات سفارش قبلی را عوض نکند.

## قرار دادن پروژه در GitHub و ارسال از VS Code

اگر هنوز مخزن مخصوص این پروژه را نساخته‌اید، ابتدا در GitHub یک Repository خالی بسازید و سپس در ترمینال VS Code اجرا کنید:

```bash
git init
git add .
git commit -m "Create TechMart e-commerce project"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
git push -u origin main
```

آدرس نمونه را با آدرس مخزن خودتان جایگزین کنید. اگر مخزن از قبل وجود دارد و فایل یا تغییرات دیگری در آن هست، ابتدا آن را با `git clone` دریافت کنید و پوشهٔ پروژه را داخل همان مخزن قرار دهید؛ سپس فقط فایل‌های همین پروژه را `git add` و commit کنید. از `git push --force` استفاده نکنید. فایل `.env` و داده‌های محلی `data/store.json` عمداً در `.gitignore` قرار دارند و نباید به مخزن عمومی ارسال شوند.

## هفت نمودار UML

فایل‌ها در پوشهٔ `diagrams` هستند:

| فایل | نوع نمودار | موضوع |
|---|---|---|
| `01-use-case.puml` | Use Case | نقش مشتری و مدیر و قابلیت‌های سامانه |
| `02-class.puml` | Class | کلاس‌های دامنه و ارتباطات |
| `03-sequence-checkout.puml` | Sequence | توالی پیام‌ها در ثبت سفارش |
| `04-activity-checkout.puml` | Activity | جریان فعالیت ثبت سفارش |
| `05-state-order.puml` | State Machine | چرخهٔ وضعیت سفارش |
| `06-component.puml` | Component | اجزای نرم‌افزار و وابستگی‌ها |
| `07-deployment.puml` | Deployment | اجزای زمان اجرا و محل استقرار |

### مشاهده و خروجی گرفتن از نمودارها

۱. در VS Code افزونهٔ **PlantUML** را نصب کنید.

۲. یکی از فایل‌های `.puml` را باز کنید.

۳. از Command Palette دستور `PlantUML: Preview Current Diagram` را اجرا کنید.

۴. برای خروجی تصویر از دستور `PlantUML: Export Current Diagram` استفاده کنید و فرمت PNG یا SVG را انتخاب کنید.

برای خروجی گرفتن، بسته به تنظیم افزونه ممکن است نصب Graphviz نیز لازم باشد. فایل‌های `.puml` منبع اصلی نمودارها هستند؛ آن‌ها را همراه پروژه نگه دارید.

## نکات مهم برای ارائهٔ دانشگاهی

- ابتدا اجرای برنامه و نقش مشتری را نشان دهید: ثبت‌نام، ورود، جست‌وجوی محصول، افزودن به سبد و ثبت سفارش.
- سپس با حساب مدیر وارد شوید و افزودن محصول و تغییر وضعیت سفارش را نمایش دهید.
- بعد نمودارهای UML را باز کنید و توضیح دهید که هر نمودار، جنبهٔ متفاوتی از همین سامانه را مدل می‌کند.
- گزینهٔ «پرداخت آزمایشی» درگاه بانکی واقعی نیست و هیچ اطلاعات کارت بانکی دریافت نمی‌کند.

## محدودیت‌های نسخهٔ آموزشی

این نسخه برای اجرای محلی و ارائهٔ دانشگاهی ساخته شده است، نه برای انتشار عمومی و دریافت سفارش واقعی. ذخیره‌سازی با JSON انجام می‌شود و Session Store در حافظهٔ فرایند Express است؛ برای استقرار واقعی باید از پایگاه دادهٔ تراکنشی (مانند PostgreSQL)، ذخیره‌ساز نشست پایدار، درگاه پرداخت معتبر، HTTPS، مدیریت امن اسرار و آزمون‌های خودکار استفاده شود. همچنین حذف محصول و عملیات مدیریتی باید در نسخهٔ عملیاتی با سیاست‌های دقیق‌تر و ثبت رویداد همراه شوند.
